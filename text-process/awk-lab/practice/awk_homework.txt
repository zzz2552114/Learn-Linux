题目清单
Q01. 打印整行和行号
题目：查看 logs/app.log 的前 3 行，输出格式为 行号:原始行。

Q02. 字段数量 NF 和最后一列 $NF
题目：读取 data/packages.txt，输出包名、字段数量和最后一列。

Q03. TSV 字段提取：主机名、角色、环境
题目：读取 data/inventory.tsv，跳过表头，输出 host、role、env。

Q04. CSV 字段提取：姓名、邮箱、角色
题目：读取 data/users.csv，跳过表头，输出 name、email、role。

Q05. key=value 配置解析
题目：读取 conf/app.env，输出非空配置项，格式为 KEY => VALUE。

Q06. OFS 控制输出分隔符
题目：从 data/users.csv 生成只含 name,role 两列的新 CSV。

Q07. 正则过滤日志级别：区分大小写
题目：从 logs/app.log 输出包含 WARN、ERROR、FATAL 的行，并显示行号。

Q08. 忽略大小写过滤日志级别
题目：从 logs/app.log 输出 WARN/warning、ERROR、FATAL 的行号和日志级别。

Q09. 数值比较：CPU 或内存过高
题目：读取 data/metrics.csv，找出 CPU >= 85 或 MEM >= 85 的记录。

Q10. printf 对齐输出报表
题目：读取 data/metrics.csv，输出 HOST、CPU、MEM 三列对齐报表。

Q11. split + 求平均：duration_ms 平均耗时
题目：从 logs/app.log 中提取所有 duration_ms=数字，输出样本数和平均耗时。

Q12. 关联数组：按 HTTP 状态码统计
题目：读取 logs/access.log，统计每个状态码的出现次数，并按状态码排序。

Q13. 认证日志：按 IP 统计失败登录
题目：读取 logs/auth.log，忽略大小写统计 Failed password 来源 IP。

Q14. BEGIN/END：软件包状态摘要
题目：读取 data/packages.txt，先输出标题，中间输出包名和状态，最后统计 installed/removed。

Q15. gsub 去单位：磁盘使用率告警
题目：读取 data/disk.txt，找出 Use% >= 85 的文件系统、使用率和挂载点。

Q16. sub/gsub 思维：配置脱敏
题目：读取 conf/app.env，输出可能包含敏感信息的 KEY，并把值替换为 ***REDACTED***。

Q17. match + RSTART/RLENGTH：提取日志片段
题目：从 logs/app.log 中提取 request_id=... 和 path=... 字段。

Q18. length/substr/index：字符串检查
题目：检查 conf/app.env 中 API_KEY 和 TOKEN 的长度、前缀，以及是否包含 live。

Q19. NF 数据质量检查
题目：检查 data/incidents.tsv 每行字段数是否与表头一致。

Q20. next：跳过注释和空行
题目：读取 conf/sshd_config，跳过注释行和空行，输出真实生效行及文件内行号。

Q21. 业务 5xx 分析：排除健康检查
题目：读取 logs/access.log，统计 HTTP 5xx，排除 /health，只输出 路径 状态码 次数。

Q22. Web 可疑请求初筛
题目：找出访问 /admin、/.env、/wp-login.php、../ 路径或 User-Agent 为 sqlmap 的请求。

Q23. SSH 暴力破解阈值
题目：统计 Failed password 来源 IP，只输出失败次数 >= 2 的 IP。

Q24. -v 传入阈值：磁盘告警可参数化
题目：用 -v threshold=85 控制磁盘使用率阈值，输出告警记录。

Q25. 进程快照：高 CPU + 按命令汇总 RSS
题目：读取 data/ps_snapshot.txt，输出 CPU >= 50 的进程，并按 COMMAND 累计 RSS。

Q26. key=value 日志聚合：按服务统计错误和平均耗时
题目：只分析 logs/app.log 的 ERROR/FATAL 行，按 service 统计错误次数和平均 duration_ms。

Q27. 按分钟和级别聚合应用日志
题目：按分钟和日志级别统计 logs/app.log 的 INFO/WARN/WARNING/ERROR/FATAL。

Q28. Kubelet 日志级别统计
题目：读取 logs/kubelet.log，按 I/W/E 统计数量。

Q29. find + awk 配置安全审计
题目：在 conf/ 中找未注释的 PermitRootLogin yes、PasswordAuthentication yes、server_tokens on;，输出 文件:行号:原始行。

Q30. find + awk 敏感信息初筛
题目：在 conf/ 和 src/ 中找 API key、token、默认密码、JWT secret、数据库凭据等敏感线索。

Q31. 多文件关联：用主机清单补全事件
题目：用 data/inventory.tsv 补全 data/incidents.tsv，输出 时间 主机 IP 角色 环境 级别 消息；未知主机输出 UNKNOWN。

Q32. 按负责人统计故障事件
题目：结合 inventory.tsv 和 incidents.tsv，只统计 ERROR/FATAL，按 owner 输出事件数。

Q33. 多文件差集：检查必装包缺失
题目：用 data/required_packages.txt 对比 data/packages.txt，输出缺失或未 installed 的包。

Q34. 目录级审计：FILENAME/FNR 定位证据
题目：在 logs、conf、src 中搜索 ERROR/FATAL/TODO/FIXME，输出 文件:行号:内容。

Q35. 多文件状态重置：按文件统计 5xx
题目：同时读取 logs/access_yesterday.log 和 logs/access.log，分别输出每个文件的 5xx 数量。

Q36. RS 记录分隔符：解析空行分隔的工单块
题目：读取 data/tickets.txt，把空行分隔的每个工单块解析为 Ticket、Host、Severity。

Q37. ORS/printf：生成逗号分隔列表
题目：读取 data/packages.txt，把 installed 包名输出成一行逗号分隔列表，末尾不要多余逗号。

Q38. 自定义函数：RSS KB 转 MB
题目：读取 data/ps_snapshot.txt，把 RSS 从 KB 转成 MB 输出。

Q39. 三元表达式：OK/WARNING/CRITICAL 分类
题目：读取 data/metrics.csv，用 warn=85、crit=90 判断cpu和mem，把每条记录分类为 OK、WARNING、CRITICAL。

Q40. awk -f 脚本化巡检报告
题目：创建 tmp/ops_report.awk，使用 -f 和 -v cpu_warn/mem_warn 生成指标巡检报告。

Q41. GNU awk：FPAT 按“字段内容”而不是分隔符切分
题目：读取 data/quoted_users.csv，用 FPAT 粗略处理“普通字段或双引号字段”，输出 name 和 role。

Q42. GNU awk：asorti 按键排序输出数组
题目：按 service 统计 logs/app.log 里 ERROR/FATAL 次数，并按服务名排序输出。
